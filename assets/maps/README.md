# Historical map scans

Each scan in this folder is listed in `sources.json` with its holder, URL, licence and usage terms. `npm test` checks that every file has an entry, every entry has a file with a matching SHA-256, and every entry states a licence. Add the entry in the same change as the file.

## Ball's Bluff

`ballsbluff/corbett-seat-of-war-1861.jpg` is V. P. Corbett's 1861 "Map of the seat of war showing the battles of July 18th, 21st & Oct. 21st 1861", from the Library of Congress. It is public domain (US publication of 1861, no LoC Rights Advisory), with no usage terms beyond the requested credit line.

Limits to know about:

- It is a regional map (about 66 x 56 cm), so the Ball's Bluff ground is a small part of the sheet. The scan is 3288 x 3888 px, half the master resolution; fetch the master from the same service if the annotation work needs more detail.
- It is not a battle plan. It shows roads, drainage, vegetation and hachures, which is what the terrain grid needs, but not unit positions at Ball's Bluff.
- Other LoC copies were checked and rejected: `lva0000218` (same map, with later hand annotation) and `gvhs01.vhs00065` (R. K. Sneden's 13 x 15.5 cm diary sketch, held by the Virginia Historical Society, which asks to be contacted about use).
